### Git y GitHub – Aplicación autónoma del flujo de trabajo

## Descripción: Práctica y manejo de comandos para la creación de un proyecto colaborativo en Git y GitHub

Objetivo: Aplicar de manera autónoma el flujo de preparación, versionamiento y colaboración de un proyecto utilizando Visual Studio Code, Python, Git y GitHub. En esta práctica no se proporcionan los comandos: cada instrucción describe una acción y el resultado esperado, y deberás determinar qué comando utilizar, ejecutarlo y comprobar su resultado.

Estructura General:
- Creación del proyecto
- Creación de carpetas y archivos necesarios
- Creación e inicialización de entorno virtual
- Instalación de Dependencias
- Creación de archivo requirements.txt
- Inicialización de repositorio
- Añadir archivos a repositorio y hacer commit
- Subir repositorio a GitHub

Tecnologías Utilizadas:
Visual Studios Code
Python
Git
GitHub

Instrucciones para preparar el entorno y dependencias:
1. Crear entorno virtual con el comando python -m venv .venv en terminal
2. Activar entorno virtual entrando a la carpeta .venv/Scripts/activate en terminal
3. Instalar dependencias en terminal con el comando pip install requests y rich
