## Criterios

- Tipo: Asignar el tipo de archivo que se desea compartir. Ya sea un archivo .txt, .word, .pdf, etc.

- Tema: Un título o clasificación del archivo, algo que asigne lo que se desea representar o se menciona en el archivo.

- Autor: Nombre completo del autor, ya sea que se haya extraído de otro lugar o que el mismo autor lo deseee publicar.

- Bibliografía: En caso de archivos formales se recomienda presentar bibliografías para mejor investigación, en caso de archivos que se hayan extraídos de alguna página, colocar el link de origen.
